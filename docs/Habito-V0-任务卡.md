# Habito V0 任务卡

> 每张任务卡应能由新的执行者单独领取，并在一次正常工作会话内完成。状态只在《Habito-V0-执行看板》中维护，本文不复制状态。

> 版本说明（2026-09-29）：本文件只维护当前 V0 的 44 张任务卡，不因新 PRD 回写或扩张已完成任务。V1 的差异、迁移顺序和拆卡入口见《Habito-V1-PRD基线与改造计划》；V1 规则确认后再建立独立任务卡。

## 通用完成定义

每张卡只有同时满足以下条件才能标记 `DONE`：

1. 任务卡的全部产物已经生成。
2. 验收标准逐条通过，证据写入执行看板。
3. 相关自动化测试已运行；无法自动化的部分有明确实机步骤和结果。
4. 没有把新需求或未确认假设静默带入实现。
5. 执行看板中的决策、问题、风险和最近交接已同步。

## D：开工决策

### D-001 确认目标设备与首发约束

- 目标：把设备相关未知项变成可执行的工程约束。
- 依赖：无。
- 输入：目标 iPad、Mac/Xcode 环境和用户偏好。
- 工作：记录 iPad 型号、iPadOS、是否孩子专用、主要方向、是否需要同时适配横竖屏、MacOS 与 Xcode 版本。
- 产物：执行看板 Q-001 至 Q-003 更新为已确认；形成环境基线。
- 验收：所有字段有事实值；无法确认的字段继续标记假设并注明最迟确认点。
- 不包含：创建 Xcode 工程。

### D-002 确认 V0 产品假设

- 目标：锁定会改变数据模型或核心交互的 V0 决策。
- 依赖：D-001。
- 工作：确认家长入口、放假行为、孩子数量、稍后提醒时长、计时是否手动完成、方向支持。
- 产物：新增决策记录；同步更新落地计划中对应假设。
- 验收：Q-004 至 Q-007 均已确认，或用户同意按现有假设推进。
- 不包含：语音场景和长期分发的最终决策。

## M0：工程与风险探针

### M0-001 建立工程与环境基线

- 目标：固定可复现的开发环境。
- 依赖：D-002。
- 工作：确认 Xcode/Swift 版本、Bundle ID 命名、部署目标、设备方向、测试 target 和本地数据策略。
- 产物：工程基线记录；需要时补充 README 的环境章节。
- 验收：下一位执行者可按记录创建相同配置；所有选择都能追溯到决策或假设。

### M0-002 建立应用壳与运行配置

- 目标：得到不含业务功能、可编译运行的 iPad SwiftUI 应用。
- 依赖：M0-001。
- 工作：创建应用和测试 target、基础目录、SwiftData 容器占位、开发/测试配置。
- 产物：可构建的工程壳。
- 验收：模拟器构建和单元测试 target 均成功；没有提前加入任务业务代码。

### M0-003 免费签名真机安装探针

- 目标：确认目标 iPad 可通过当前 Apple ID 安装运行。
- 依赖：M0-002。
- 工作：连接设备、处理开发者模式与签名、安装并启动；记录签名日期和预期观察窗口。
- 产物：真机安装证据；M5-006 的观察起点。
- 验收：冷启动、退到后台、重新进入均正常；看板记录设备与构建信息。

### M0-004 本地通知最小探针

- 目标：在投入完整 UI 前验证核心系统能力。
- 依赖：M0-003。
- 工作：仅建立开发探针，安排 2 分钟后通知，测试前台、后台、锁屏、App 被终止及点击唤起。
- 产物：各状态的实测记录和已知系统限制。
- 验收：系统允许通知时，至少锁屏和 App 被终止场景可收到并点击；异常能区分授权/系统设置与应用错误。

### M0-005 M0 风险结论与技术基线

- 目标：把探针结果转为继续/调整/停止的明确结论。
- 依赖：M0-004。
- 工作：整理通知、签名、系统版本和方向风险，确认是否调整部署目标或计划。
- 产物：决策与风险表更新。
- 验收：M0 放行条件有明确结论；若不放行，记录阻塞和替代路线。

## M4：通知闭环
