# Habito V1 已确认规则

> 2026-10-05：用户明确确认聊天中 1～13 项推荐，后置项暂不确认。对应执行看板 DEC-016～029。本文件是实现/测试规则索引，不是全部 V1 已实现或 V0 已放行的声明。

## 1. 版本与权限边界

- 进入 V1，保留 V0 真机未验收项。唯一任务状态仍由执行看板维护。
- 沿用单孩子本地优先、可见家长入口、四位 ASCII PIN 与 Keychain；不接 CloudKit。设备是否主要由孩子使用尚未确认。
- 模拟器/测试夹具迁移可以推进；不读取、删除或覆盖家庭数据库，不安装覆盖旧签名观察版本，不推送提交。

## 3. 正反馈方向与数值确认（2026-10-08更新）

- 已确认：增强正反馈和游戏感。奖励反馈围绕真实完成、真实入账和宠物积极回应；不把“像游戏”解释为无限刷奖励或重复点击重复发奖。
- 设计细化见《Habito-V1-奖励正反馈设计》。这是执行设计草案，不等于用户逐项确认了动画、声音或数值。
- DEC-033已确认：每100有效XP升一级、食物5Coin/份、喂食Bond+1、当天喂过开心/次日平静、无衰减或惩罚。实现口径：0XP起Lv.1，等级由有效XP派生，亲密度来自成功喂食事实。
- 仍未确认：各分类默认 XP/Coin、自主奖励默认值；设备用途；长期分发；声音/触觉。家长仍可显式设置任务奖励，不需等待分类默认值。
- 先实现可测试的显式奖励输入、不可变账本与派生查询，不预埋未确认默认值。测试中的数值只是局部合成输入，不是产品默认参数。
- 宠物数值决策已完成，后续执行见《Habito-V1-剩余功能任务卡》；不得继续以参数未确认阻塞成长与喂食。已有独立审核/奖励规则不变。

## 4. 可追溯验收输入

- 提醒 19:30，提交 19:29:59 / 19:30:00 / 19:30:01；通过时间统一设次日，结果仍只由关联提交判定。
- 提交奖励为测试输入，之后编辑成不同测试输入再通过：只结算原快照；退回重提再通过：只结算新提交快照。
- 重复确认、重复通过、重启重试：只有一份有效奖励；重复撤销只有一份冲正。
- 奖励已花掉：余额不足撤销失败，整个对象图和账本保持原状；不消除宠物消费痕迹。
- 合成旧库含历史完成、进行中/暂停计时、单日 detached 覆盖、通知映射、放假与 PIN 引用：迁移后逐项一致，没有补奖。
