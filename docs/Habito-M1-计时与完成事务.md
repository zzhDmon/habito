# Habito M1 计时与完成事务

## 1. 核心约束

- 同一任务实例最多一个状态为 `running` 或 `paused` 的未结束会话。
- 计时不依赖后台持续执行。运行中有效时长为 `accumulatedActiveSeconds + now - lastResumedAt`。
- 暂停时把当前运行段累加到 `accumulatedActiveSeconds`；继续时只更新 `lastResumedAt`。
- 完成时结束当前活动会话，并把该实例所有计时段的有效秒数之和写入唯一 `CompletionRecord`。
- 达到目标时长不会自动完成，完成始终由孩子或家长明确触发。

## 2. 幂等操作

- 重复开始返回已有活动会话，不创建第二条。
- 已暂停时重复暂停、运行中重复继续均不改变时间锚点。
- 已完成时重复完成返回现有记录，不创建第二条。
- 已撤销状态下重复撤销返回 `false`，不产生额外写入。

## 3. 撤销与多段计时

撤销完成会删除完成记录并把实例恢复为 `pending`，但旧计时会话保持 `ended`，避免伪造历史。再次开始会创建新会话；下次完成记录累计该实例全部已结束会话和当前活动会话的有效时长。

## 4. 时间异常

所有操作时间由调用方注入。如果系统时间早于会话开始、最近继续或已经结束的时间，服务会明确报错，不把负数静默夹为零。Feature 层应提示用户检查系统时间，并保留诊断日志。
