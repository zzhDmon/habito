# Habito M1 规则展开器

## 1. 职责边界

`TaskRecurrenceExpander` 把已校验的 `TaskRecurrence`、一天内分钟数和请求日期范围转换为 `ScheduledTaskCandidate`。它是纯领域服务：不读取当前时间、不访问 SwiftData、不处理日期覆盖，也不创建或取消通知。

后续任务分工：

- M1-004 在候选上应用放假、上课与单日覆盖。
- M1-005 为最终候选分配稳定身份并幂等写入 SwiftData。
- M2 通知服务根据已持久化实例安排和清理通知。

## 2. 输入与输出

- 输入日期使用 `LocalDate`，表示不带时区的业务日历日期。
- `timeOfDayMinutes` 是本地午夜后的分钟数，范围为 `0...1439`。
- 请求范围和规则生效范围都包含首尾日期；实际展开范围为两者交集。
- 输出同时包含本地日期和绝对 `Date`，列表按本地日期升序排列。

## 3. 时间与夏令时策略

日历和时区必须由组合根显式注入，V0 使用公历和家庭当前业务时区。展开器不会读取 `Calendar.current` 或 `TimeZone.current`，因此测试和真机结果不依赖运行环境。

对于夏令时切换：

- 本地时刻不存在时，顺延到当天可表示且保留较小时间分量的时刻，例如 `02:30` 顺延为 `03:30`。
- 本地时刻重复出现时，固定选择第一次。
- 若调整后落到另一个本地日期，则返回明确错误，不静默生成错误日期的候选。

## 4. 已确认与假设

- 已确认：V0 支持一次性与按星期重复规则。
- 已确认：日期键使用 `yyyy-MM-dd`，星期值与 Foundation `Calendar` 一致。
- `ASSUMPTION`：V0 的业务日历使用公历；如果未来支持其他历法，需要同时调整 `LocalDate` 的公历校验约束。
- `ASSUMPTION`：夏令时缺失时刻采用顺延策略，而不是跳过当天任务或要求家长重新选择时间。
