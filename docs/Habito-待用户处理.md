## 3. V1 产品规则

下表原推荐方向已于本次聊天确认；具体提交快照、退回与余额不足边界见 DEC-016～029，不再要求重复确认。

| 决策 | 推荐值 | 为什么要明确 |
|---|---|---|
| 家长 PIN / 入口 | 沿用四位 PIN + 可见点击入口 | 已有可靠实现与无障碍路径，可避免无必要迁移 |
| 自主完成 | 严格早于实例的提醒时间快照；等于/晚于提醒不算自主 | 系统实际送达无法作为可靠时间真相 |
| 验收退回与重提 | 保留历次提交，退回后可重提；最终通过只发一次奖励 | 决定状态机与幂等键 |
| 完成撤销 | 保留原奖励交易，新增冲正；不删除账本历史 | 保证余额与历史可追溯 |
| XP 与宠物等级 | 一个 XP 总账；宠物成长阶段由累计 XP 映射 | 避免维护两套互相矛盾的等级体系 |
| 旧任务迁移 | 奖励默认为 0，旧完成时间类型为未知，不补发历史奖励 | 避免迁移时意外发奖或伪造自主完成 |
| 等待验收的提醒 | 建议不再提醒孩子做已提交任务，验收完成前不发奖励 | 决定旧计时/通知与新审批状态的衔接 |
