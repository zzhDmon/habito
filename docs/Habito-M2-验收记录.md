# Habito M2 孩子闭环验收记录

## 1. 放行结论

- 结论：`PASS`，M2 可放行进入 M3 家长闭环。
- 验收日期：2026-09-23。
- 验收环境：Xcode 27.0、iOS 27.0 iPad Pro 13-inch (M5) 横屏模拟器；iPadOS 17.2 模拟器用于最低部署版本构建。
- 缺陷结论：无 P0、无 P1；1 项既有 P2/兼容性风险继续由 `R-009` 跟踪。

## 3. 自动验证

- iOS 27 完整测试：73 个 Swift Testing 单元测试与 1 个 XCUITest UI 闭环全部通过。
- 本地化目录：92 个字符串键均存在非空简体中文值；新增测试会阻止漏译键进入后续阶段。
- 静态分析：`xcodebuild analyze` 通过。
- 最低版本：iPadOS 17.2 `build-for-testing` 通过，包含 App、单元测试和 UI 测试 target。
- 工程卫生：Swift 严格格式、字符串目录 JSON、工程 plist 和 diff 检查通过。

## 4. 缺陷与风险

| 等级 | 编号 | 说明 | 处理 |
|---|---|---|---|
| P2 | R-009 | Xcode 27 提示未来系统可能忽略 `UIRequiresFullScreen` 并要求声明全部方向；V0 当前仍按已确认的横屏首发约束运行。 | M5-001 复核窗口与方向适配；当前自适应布局不依赖固定像素 |

构建日志中的 AppIntents 元数据跳过提示不属于产品缺陷：项目未依赖 AppIntents，处理器按预期跳过提取。

## 5. 测试设施边界

- UI 测试种子与独立存储仅在 Debug 构建且显式传入 `--habito-ui-testing` 时启用。
- `--habito-ui-reset` 只清理 UI 测试专用容器；正式 Habito 数据不会被读取、覆盖或删除。
- 稳定可访问性标识位于叶子交互控件，不依赖中文文案或具体横屏层级。
- 该设施借鉴 Kado 的工程思路并针对 Habito 重新实现；未复制 Kado 源码，因此本次变更不产生第三方代码归属要求。
