# Habito 文档入口

按以下顺序使用：

1. `Habito-V0-执行看板.md`：当前状态、进行中任务、阻塞和最近交接。
2. `Habito-V0-任务卡.md`：44 张可独立领取、独立验收的任务卡。
3. `Habito-V0-落地计划.md`：V0 产品范围、页面、数据模型、通知方案和验收基线。
4. `Habito-V1-PRD基线与改造计划.md`：新 PRD、相对当前 V0 的差异、模型迁移和 V1 分阶段实施顺序。
5. `Habito-环境基线.md`：当前 Mac、Xcode、SDK 和目标 iPad 信息。
6. `Habito-项目交接.md`：最初的项目背景与方向。
7. `Habito-Kado-工程复用评估.md`：外部 MIT 项目可借鉴的测试、无障碍和通知工程模式。
8. `Habito-M2-验收记录.md`：孩子闭环自动化、横屏走查证据与缺陷结论。
9. `Habito-M4-验收记录.md`：通知集成缺陷、自动化证据和目标真机逐项验收矩阵。
10. `Habito-待用户处理.md`：设备连接、签名观察、家庭试用与 V1 产品待确认事项。
11. `Habito-V1-决策草案与验收矩阵.md`：尚未批准的 V1 规则、状态机边界、固定测试矩阵和候选任务拆分；不能视为正式开工授权。

根目录的 `AGENTS.md` 是执行规则，必须保留在根目录，便于后续执行者自动发现。
