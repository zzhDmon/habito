## 2. V1-M3-002：家长通过与退回

- 审核请求绑定提交 ID。通过按原快照发奖，完成时刻为原提交，自主性仍按原提醒；真实审核/奖励入账时刻单列。新增 parentApproval 来源与版本 2 语义，**持久化字段/schema 形状没有变化**，冻结版本不改。直接完成与旧完成均不能伪造家长通过来源。
- TaskSubmissionReviewService 同步主 actor、干净/同上下文、关闭自动保存，一次 save 提交审核结果、完成关系/状态和成对奖励；退回仅保存结果/更新时间，无完成或交易，不删除计时/提交。新收据只在保存后返回。
- 两侧审计按稳定外键核对快照、提交/审核时刻、来源、原奖励与冲正、当前未撤销关系，避免递归调用校验。坏等待/关联/账本/状态明确拒绝，不自动补奖。待验收改配置与次日通过不改变原快照，自主三边界/零奖励均覆盖。
- 旧退回请求只返回其旧结果，不审后来新提交；通过/退回互相冲突明确拒绝。真正撤销保留已通过审计，允许新事件重提；原通过重试返回 didReview=false/rewardIsRevoked=true，不重新发奖，也不改后来的等待或新完成。已消费导致币不足时，撤销整次拒绝，审核/完成/XP/消费原样。
