# Habito UI-R1 视觉规格 v0.1

> UI-R1-002A，2026-10-08。用于下一步可审阅样稿；候选配色与角色造型尚未得到样稿确认，不宣称已在产品中落地。方向依据DEC-031：日系漫画成长冒险，儿童明显漫画化、家长保持效率。

## 1. 设计主张

孩子打开的是与小狗一起经历的“今天这一话”。用暖纸底、深墨描边、不等宽漫画格、角色越框和少量网点构成界面。阅读顺序清楚：今天要做什么 → 当前最适合开始的任务 → 完成后真实收获。漫画英文只作装饰，主要信息和动作均为简短中文。

儿童首页使用一大一小的叙事格，而不是所有任务都做成同样的大圆角卡片；重点任务比普通任务更醒目。家长表单保留系统Form/List及原导航，仅在标题、语义色、任务图标和分区上统一品牌。禁止用分镜延迟操作、把零奖励改成假奖励、把未确认等级或饥饿值画成既有事实。

## 2. 候选语义颜色

以下是设计候选；产品落地时扩展现有HabitoDesign，不并存第二套长期令牌。透明叠色必须再次按最终合成颜色验收。

| 语义 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| paper | #FFF7E8 | #1D2524 | 页面纸底 |
| panel | #FFFDF7 | #27312F | 信息格底，保证文字不覆盖纹理 |
| ink | #29241F | #F6EFDF | 正文/主要轮廓 |
| secondaryInk | #655B50 | #BFCABF | 日期、说明；不用低透明正文 |

| successInk | #356049 | #D9E7C5 | 完成语义，不独自表示状态 |

## 3. 字体、布局与组件

- 中文继续使用系统语义字体，避免下载展示字体和新的字体许可依赖。标题通过heavy/bold、布局和标点体现漫画感；正文body，说明callout，次要信息subheadline。金额可用monospacedDigit，但不能固定缩小来塞进卡片。
- 主标题largeTitle或title，按容器与Dynamic Type排版；辅助字号转换为单列。英文CLEAR/BONUS若使用只作隐藏于读屏的装饰，中文“完成啦”“自己完成！”必须可读。
- 复用Spacing的4/8/16/24/32 pt；主要信息格内边距24，紧凑行16。漫画格间留16～24，手机式窄栏按内容调整，不锁定屏幕尺寸。
- 主外框候选3 pt，次级2 pt；转角8～12 pt与现有24 pt圆卡形成有意区分。轻微不规则只用于外轮廓，文本/热区保持稳定轴线；不随机抖动布局。
- 阴影候选深墨偏移4 pt、无模糊，只在重点格/主按钮使用；深色模式以边线层级替代重黑阴影。正文区域无网点；装饰网点占画面小面积，Reduce Transparency时用不透明纯色。
- 主按钮文字清晰、整块可点，最小44×44 pt，常规高度56 pt且允许大字增高。次按钮保持语义清楚，按压反馈不影响点击尺寸。
- 首批组件：MangaPanel、SpeechBubble、MangaStamp、主/次按钮样式、任务图标入口、角色图像容器。资产概览复用既有金额View的数据输入。命名在实现卡最终确定，当前不创建空类型。
- 气泡仅负责展示短句，不能成为另一个任务/奖励状态来源。装饰气泡尾巴、星点和拟声词对VoiceOver隐藏；按钮标签、任务状态、金额和进度保持可读顺序。

## 4. 三类样稿的内容边界

| 样稿 | 必备内容 | 不得误导 |
|---|---|---|
| 今日首页 | 今日标题、小狗招呼、真实结构的3/6示例进度、推荐阅读任务、其他任务、累计XP/Coin入口、家长入口 | 演示数据明确标为样稿，不显示未经定义的连续天数；资产称累计，未完成任务不恐吓 |
| 完成奖励 | 已完成、普通/自主区分、真实结构的XP/Coin示例、可立即继续、零奖励变体、待确认变体 | 自主额外Coin不能改成Bonus XP；待确认不显示到账；关闭不等于撤销或确认别的收据 |
| 宠物主页 | 同一只狗、名字、角色回应、已有名字编辑的接续说明；喂食区域说明为后续功能 | 无假Lv.1/Bond/Mood/食物价格；样稿不代表业务可用，不把饥饿情绪当惩罚 |

布局验证包含横屏常规、窄栏/最大字号的单列阅读顺序。样稿用于确认方向；真实SwiftUI尺寸、命中区域、VoiceOver和性能在接入卡验证。

## 5. 动效候选

沿用现有反馈0.45秒spring为上限参考；正常完成只做一次小幅印章/角色入场。正文、金额、继续按钮首帧就能看到和操作。Reduce Motion直接显示终态；不做背景持续漂浮、常驻粒子或每卡独立计时器。事件资格继续由现有ViewModel的稳定ID/claim控制，不能依赖onAppear次数。
